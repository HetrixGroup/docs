Mit dem **Server Importer** überträgst du Daten von einem anderen Anbieter oder einem entfernten Server bequem auf deinen Server bei uns. Praktisch, wenn du zu uns umziehst.

## Verbindung herstellen

<Steps>
  <Step title="Bereich Server Importer öffnen">
    Öffne im Panel den Bereich Server Importer.
  </Step>
  <Step title="Zugangsdaten eingeben">
    Trage Host und Port des entfernten Servers sowie Benutzername und Passwort ein. Diese Daten bekommst du von deinem bisherigen Anbieter.
  </Step>
  <Step title="Pfade festlegen">
    Lege den Quellpfad fest, aus dem importiert wird, und den Zielpfad, in den die Dateien geschrieben werden.
  </Step>
  <Step title="Protokoll wählen und verbinden">
    Wähle das Verbindungsprotokoll, zum Beispiel SFTP, und klicke auf Connect, um den Import zu starten.
  </Step>
</Steps>

<Tip>
  Häufig genutzte Verbindungen kannst du über Saved Profiles speichern und beim nächsten Mal direkt wieder auswählen.
</Tip>

<Warning>
  Stelle sicher, dass der Zielserver während des Imports gestoppt ist, damit keine Dateien gleichzeitig geändert werden. Ein Backup vor dem Import ist empfehlenswert.
</Warning>
