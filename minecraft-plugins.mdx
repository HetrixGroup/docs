Mit Plugins erweiterst du deinen Minecraft Server um neue Funktionen. Im Bereich **Plugins** durchsuchst und verwaltest du sie direkt im Panel. Voraussetzung ist eine Servervariante, die Plugins unterstützt, zum Beispiel Paper, Purpur oder Spigot.

## Plugins durchsuchen und installieren

Der Bereich Plugins ist in zwei Reiter unterteilt: **Browse Plugins** zum Finden neuer Plugins und **Manage Plugins** für bereits installierte.

<Steps>
  <Step title="Bereich Plugins öffnen">
    Öffne im Panel den Bereich Plugins und bleibe im Reiter Browse Plugins.
  </Step>
  <Step title="Passendes Plugin finden">
    Nutze die Suche und die Filter, um das richtige Plugin zu finden. Du kannst unter anderem nach Anbieter, Loader und Version filtern und die Ergebnisse sortieren.
  </Step>
  <Step title="Details ansehen">
    Über Details siehst du weitere Informationen zum Plugin. Über das Symbol daneben öffnest du die Herkunftsseite des Plugins.
  </Step>
  <Step title="Installieren">
    Klicke auf Install. Das Plugin wird auf deinen Server geladen.
  </Step>
  <Step title="Server neu starten">
    Starte den Server neu, damit das Plugin geladen wird.
  </Step>
</Steps>

## Installierte Plugins verwalten

Im Reiter Manage Plugins siehst du alle installierten Plugins. Dort kannst du sie bei Bedarf wieder entfernen oder aktualisieren.

## Manuell installieren

Möchtest du eine eigene Plugin Datei einspielen, nutzt du den Bereich Files.

<Steps>
  <Step title="Files öffnen">
    Wechsle in den Bereich Files.
  </Step>
  <Step title="In den Plugins Ordner laden">
    Lade die Datei in den Ordner plugins deines Servers.
  </Step>
  <Step title="Server neu starten">
    Starte den Server neu, damit das Plugin aktiv wird.
  </Step>
</Steps>

<Warning>
  Installiere nur Plugins aus vertrauenswürdigen Quellen und achte darauf, dass sie zu deiner Serverversion und deinem Loader passen. Erstelle vorher ein Backup.
</Warning>
