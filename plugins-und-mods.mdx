---
title: "Plugins und Mods installieren"
description: "Erweitere deinen Server mit Plugins und Mods über das Gamepanel."
icon: "puzzle-piece"
---

Mit Plugins und Mods gibst du deinem Server neue Funktionen und ein individuelles Spielerlebnis. Beliebte Spiele und Mods lassen sich über Ein Klick Installationen einrichten.

<Note>
  Welche Optionen zur Verfügung stehen, hängt vom jeweiligen Spiel ab. Details findest du auf der Seite des jeweiligen Spiels.
</Note>

## Mit einem Klick installieren

<Steps>
  <Step title="Installer öffnen">
    Öffne im Gamepanel den Bereich für Plugins oder Mods.
  </Step>
  <Step title="Inhalt auswählen">
    Suche das gewünschte Plugin oder Modpack und starte die Installation mit einem Klick.
  </Step>
  <Step title="Server neu starten">
    Starte deinen Server neu, damit die neuen Inhalte geladen werden.
  </Step>
</Steps>

## Manuell installieren

Wenn du eine eigene Datei einspielen möchtest, nutzt du den Datei Manager im Panel.

<Steps>
  <Step title="Datei Manager öffnen">
    Wechsle in den Datei Manager deines Servers.
  </Step>
  <Step title="Datei hochladen">
    Lade die Plugin oder Mod Datei in den passenden Ordner deines Servers.
  </Step>
  <Step title="Server neu starten">
    Starte den Server neu, damit die Datei aktiv wird.
  </Step>
</Steps>

<Warning>
  Installiere nur Plugins und Mods aus vertrauenswürdigen Quellen und achte darauf, dass sie zu deiner Serverversion passen. Erstelle vorher ein Backup.
</Warning>
