Mit Plugins erweiterst du deinen Rust Server um neue Funktionen wie Kits, Teleportation oder Verwaltungshilfen. Im Bereich **Rust Plugins** findest und verwaltest du sie direkt im Panel.

## Plugins durchsuchen und installieren

<Steps>
  <Step title="Bereich Rust Plugins öffnen">
    Öffne im Panel den Bereich Rust Plugins.
  </Step>
  <Step title="Plugin finden">
    Nutze die Suche und die Filter. Du kannst nach Anbieter filtern, die Ergebnisse nach Beliebtheit sortieren und die Anzahl pro Seite festlegen. Zu jedem Plugin siehst du Downloads, Aktualität, Größe und Themen wie mechanics oder administration.
  </Step>
  <Step title="Installieren">
    Klicke bei einem Plugin auf Install. Es wird auf deinen Server geladen.
  </Step>
  <Step title="Server neu starten">
    Starte den Server neu, damit das Plugin aktiv wird.
  </Step>
</Steps>

## Installierte Plugins ansehen

Über die Schaltfläche Installed zeigst du dir alle bereits installierten Plugins an. Von dort kannst du sie verwalten oder wieder entfernen.

<Tip>
  Beliebte Rust Plugins sind zum Beispiel Kits, Teleportationssysteme, Werkzeuge zum Bauen und Entfernen von Objekten sowie Hilfen zur Serververwaltung.
</Tip>

## Manuell installieren

Eigene Plugin Dateien spielst du über den Bereich Files ein. Lade die Datei in den passenden Ordner deines Servers und starte den Server anschließend neu.

<Warning>
  Installiere nur Plugins aus vertrauenswürdigen Quellen und achte darauf, dass sie aktuell sind. Erstelle vorher ein Backup.
</Warning>
