Diese Anleitung führt dich durch die grundlegende Einrichtung deines Gameservers im Gamepanel. Die Schritte gelten für die meisten Spiele. Spielspezifische Details findest du auf den jeweiligen Unterseiten.

## Server starten und stoppen

<Steps>
  <Step title="Server im Panel öffnen">
    Melde dich im Gamepanel an und wähle deinen Server aus der Übersicht aus.
  </Step>
  <Step title="Server starten">
    Klicke auf Starten. Beim ersten Start werden alle benötigten Dateien vorbereitet. Das kann einen Moment dauern.
  </Step>
  <Step title="Status prüfen">
    Sobald die Konsole anzeigt, dass der Server bereit ist, kannst du über die angezeigte Adresse und den Port beitreten.
  </Step>
</Steps>

## Grundeinstellungen anpassen

Die wichtigsten Einstellungen deines Servers passt du direkt im Panel an. Dazu gehören zum Beispiel der Servername, die maximale Spieleranzahl, das Passwort und spielspezifische Optionen.

<Steps>
  <Step title="Einstellungen öffnen">
    Wechsle im Panel in den Bereich Einstellungen deines Servers.
  </Step>
  <Step title="Werte anpassen">
    Ändere die gewünschten Werte, etwa Servername oder Spieleranzahl. Speichere deine Änderungen.
  </Step>
  <Step title="Server neu starten">
    Viele Einstellungen werden erst nach einem Neustart aktiv. Starte deinen Server neu, damit die Änderungen greifen.
  </Step>
</Steps>

## Konfigurationsdateien bearbeiten

Für feinere Anpassungen nutzt du den Datei Manager im Panel. Dort öffnest und bearbeitest du Konfigurationsdateien direkt im Browser.

<Warning>
  Bearbeite Konfigurationsdateien nur, wenn du weißt, was die einzelnen Werte bewirken. Erstelle vor größeren Änderungen immer ein Backup, damit du bei Bedarf zurück kannst.
</Warning>

## Server erreichbar machen

Deine Serveradresse und der Port stehen im Panel in der Serverübersicht. Gib diese Adresse an deine Mitspieler weiter, damit sie beitreten können. Der Schutz über Cloudflare ist bereits aktiv und muss von dir nicht eingerichtet werden.
