Diese Anleitung zeigt dir, wie du deinen Rust Server einrichtest und betreibst. Über das Panel steuerst du den Server, installierst Plugins und planst Wipes.

## Server starten

<Steps>
  <Step title="Server auswählen">
    Wähle deinen Rust Server oben über die Auswahl Select a server aus.
  </Step>
  <Step title="Server starten">
    Klicke in der Statusleiste auf Start. Der erste Start kann etwas länger dauern, da Rust die nötigen Dateien vorbereitet.
  </Step>
  <Step title="Verbinden">
    Sobald der Server online ist, verbindest du dich über die angezeigte Adresse und den Port.
  </Step>
</Steps>
